# mini_ai C++20 documentation

This branch contains the complete C++ replacement. See the repository README for build, training, generation, and checkpoint commands. Checkpoints include parameters, Adam moments, and resume counters.

## Generation CLI

After training a checkpoint, run:

```sh
./build/mini_ai_generate --checkpoint mini_ai.ckpt --tokens 64 --temperature 0.8 "Hola, mundo"
```

`--tokens` (also `--max-tokens`) is the number of new bytes to sample. Temperature must be finite and greater than zero. The byte tokenizer preserves arbitrary UTF-8 input by encoding each byte; generation uses the model's fixed context and prints the retained prompt together with generated bytes. Missing or incompatible checkpoints and malformed options produce a non-zero exit status and a concise diagnostic on stderr.
